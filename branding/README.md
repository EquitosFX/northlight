# Skyfall artwork

- `SKYFALL_S_Monogram.svg`, `SKYFALL_App_Icon.svg`, `SKYFALL_Wordmark.svg`: master artwork.
- `s_geometry.py`: how the S is built (concentric bands one unit wide around two centres a
  half-turn apart, joined by 45° bands, with flat cuts at 3.75 and notches at 2.75 units).
  The app's `ic_skyfall_s.xml`, `ic_app.xml` and `banner.xml` are drawn from it.
- Lettering is Figtree (SIL Open Font License), converted to outlines.
